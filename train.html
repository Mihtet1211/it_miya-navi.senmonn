電車（ でんしゃ ） ・バス・自転車（ じてんしゃ ） のルール

日本（ にほん ） の電車（ でんしゃ ） やバスでは、
周り（ まわり ） の人（ ひと ） への配慮（ はいりょ ） が大切（ たいせつ ） です。

🚃 基本的（ きほんてき ） なマナー

🔇

車内（ しゃない ） では静か（ しずか ） にする

電車（ でんしゃ ） やバスの中（ なか ） では、大きな（ おおきな ） 声（ こえ ） で話したり（ はなしたり ） 、 音楽（ おんがく ） を大きな（ おおきな ） 音（ おと ） で聞いたり（ きいたり ） しないようにしましょう。

📱

携帯電話（ けいたいでんわ ） の使い方（ つかいかた ） に注意（ ちゅうい ） する

通話（ つうわ ） はできるだけ控えましょう（ ひかえましょう ） 。 音（ おと ） が出ない（ でない ） ように設定（ せってい ） することも大切（ たいせつ ） です。

🚪

乗り降り（ のりおり ） するとき

降りる（ おりる ） 人（ ひと ） を先（ さき ） にしてから乗りましょう（ のりましょう ） 。 ドアの前（ まえ ） では立ち止まらない（ たちどまらない ） ようにします。

💺

席（ せき ） を必要（ ひつよう ） な人（ ひと ） にゆずる

高齢者（ こうれいしゃ ） 、妊婦（ にんぷ ） 、けがをしている人（ ひと ） などには 席（ せき ） をゆずりましょう。

🎒

大きな（ おおきな ） 荷物（ にもつ ） に注意（ ちゅうい ） する

混雑（ こんざつ ） しているときは、リュックなどの荷物（ にもつ ） を 前（ まえ ） に持つ（ もつ ） ようにしましょう。

🚲 自転車（ じてんしゃ ） のルール

⬅️

車道（ しゃどう ） の 左側（ ひだりがわ ） を 走る（ はしる ）

自転車（ じてんしゃ ） は 原則（ げんそく ） として 車道（ しゃどう ） の 左側（ ひだりがわ ） を 走ります（ はしります ） 。道路（ どうろ ） の 標識（ ひょうしき ） や 表示（ ひょうじ ） も 守りましょう（ まもりましょう ） 。

🚶

歩道（ ほどう ） は 歩く（ あるく ） 人（ ひと ） を 優先（ ゆうせん ）

標識（ ひょうしき ） などで 歩道（ ほどう ） を 走れる（ はしれる ） 場合（ ばあい ） も、車道寄り（ しゃどうより ） をゆっくり 走ります（ はしります ） 。歩く（ あるく ） 人（ ひと ） のじゃまになるときは 止まります（ とまります ） 。

🚦

信号（ しんごう ） と 一時停止（ いちじていし ） を 守る（ まもる ）

信号（ しんごう ） を 守り（ まもり ） 、「止まれ（ とまれ ） 」の 標識（ ひょうしき ） では 必ず（ かならず ） 止まります（ とまります ） 。左右（ さゆう ） の 安全（ あんぜん ） を 確認（ かくにん ） しましょう。

💡

夜（ よる ） はライトをつける

暗く（ くらく ） なったら、必ず（ かならず ） ライトをつけましょう。反射材（ はんしゃざい ） も 使う（ つかう ） と、周り（ まわり ） から 見えやすく（ みえやすく ） なります。

🚫

お 酒（ さけ ） ・スマホに 注意（ ちゅうい ）

お 酒（ さけ ） を 飲んだら（ のんだら ） 自転車（ じてんしゃ ） に 乗って（ のって ） はいけません。運転中（ うんてんちゅう ） にスマホで 通話（ つうわ ） したり、画面（ がめん ） を 見続けたり（ みつづけたり ） してはいけません。

🪖

ヘルメットで 頭（ あたま ） を 守る（ まもる ）

すべての 年齢（ ねんれい ） で、ヘルメットをかぶるよう 努める（ つとめる ） ことが 求められて（ もとめられて ） います（努力義務（ どりょくぎむ ） ）。

参考（ さんこう ） ：警察庁（ けいさつちょう ） の 自転車（ じてんしゃ ） の 交通（ こうつう ） ルール

💡 覚えて（ おぼえて ） おきたいこと

日本（ にほん ） では「周り（ まわり ） の人（ ひと ） に迷惑（ めいわく ） をかけない」 ということが大切（ たいせつ ） にされています。
